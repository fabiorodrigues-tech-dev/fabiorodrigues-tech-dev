### 🎯 Sobre Mim

* **Back-End Core:** Especialista em Java 21 LTS, Spring Boot 3.3, Clean Architecture (Ports & Adapters), TDD (JUnit 5 & Mockito) e APIs RESTful.
* **Front-End & Creative Engineering:** Desenvolvimento de interfaces reativas de alta performance com React 19, TypeScript, Vite e Tailwind CSS, aplicando design systems avançados e efeitos imersivos de macOS Liquid Glass.
* **IA Aplicada & Agentes:** Implementação de servidores Model Context Protocol (MCP) com Spring AI, assistentes de voz neurais autônomos (Vapi, Twilio, ElevenLabs) e integração de fluxos assíncronos com LLMs.
* **Design & Product Engineering:** Bacharel em Design pela Faculdade Boa Viagem (UniFBV) — unindo Figma to Code, UI/UX e arquitetura visual orientada a design systems.
* **DevOps & Cloud:** Containerização com Docker, pipelines de CI/CD automatizados via GitHub Actions e deploy em Cloud (Render/Vercel).
* **📍 Localização:** Recife, PE - Brasil *(Disponível para atuação presencial, híbrida ou remota)*.
